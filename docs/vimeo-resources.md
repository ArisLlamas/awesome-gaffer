# GafferHQ Vimeo Collection

Reviewed September 29, 2026. We inventoried [GafferHQ's collection](https://vimeo.com/gafferhq) through its public listing and Vimeo oEmbed metadata. The [catalogue](video-catalog.json) lists the first 30 returned entries with publisher, upload date, and duration; it is not a full archive.

**Evidence limit:** the summaries below paraphrase publisher descriptions. Vimeo requires a login for video and caption extraction, so we claim no visual or spoken-content review here. Treat these entries as discovery pointers until someone watches them; we include no invented timestamps.
